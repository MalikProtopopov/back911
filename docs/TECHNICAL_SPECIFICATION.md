# Техническое задание: Сайт для 911

**Дата извлечения:** 2025-12-26  
**Источник:** PDF документ "Сайт для 911"

---

## 📋 Общее описание

Оптимизированный под поисковые движки сайт для продвижения **4 типов услуг**:

1. **Автовышка**
2. **Эвакуатор**
3. **Доставка топлива**
4. **Выездной шиномонтаж**

---

## 🧩 Блоки сайта

Сайт должен содержать следующие блоки:

1. **Ссылка на приложение** - блок для перехода в мобильное приложение
2. **Блок-призыв к действию** (CTA) - призыв к заказу услуги
3. **Описание услуги** - детальное описание каждой услуги
4. **Прайс-лист** - цены на услуги
5. **Преимущества** - преимущества использования сервиса
6. **Блок для оставления заявки** - форма заявки
7. **Блок контактов** - контактная информация

---

## 💰 Что входит в стоимость разработки

1. **Сбор семантического ядра** - для написания текстов на сайт, которые с большей вероятностью привлекут клиентов
2. **Настройка интеграции формы заявки с приложением** - интеграция формы заявки с мобильным приложением
3. **Дизайн, разработка, тестирование сайта** - полный цикл разработки
4. **Написание текстов** - контент для сайта

---

## 🚀 Продвижение сайта

### SEO сопровождение

**Стоимость:** 40,000 рублей в месяц

**Что входит в стоимость:**
- Техническая оптимизация сайта
- Контентная оптимизация сайта
- Закупка ссылок

**Задача:** Привлечение заявок на сайт и в приложение

**Ключевые метрики:**
- Количество заявок с сайта
- Количество скачиваний приложения с сайта

**Как отслеживать метрики:**
- Ежемесячный отчет по проделанной работе

**Время до результата:** В среднем сайты выходят в топы за **6-8 месяцев**

---

### Контекстная реклама

**Стоимость:** 45,000 рублей в месяц за работу + Бюджет (от 20,000-25,000 руб/мес)

**Что входит в стоимость:**
- Создание объявлений
- Настройка аудитории
- Подбор запросов, по которым будет выходить реклама
- Оптимизация рекламных кампаний

**Задача:** Привлечение заявок на сайт и в приложение

**Ключевые метрики:**
- Количество заявок с сайта
- Количество скачиваний приложения с сайта
- Цена заявки
- Цена скачивания

**Как отслеживать метрики:**
- Ежемесячный отчет по проделанной работе
- Яндекс.Метрика

**Время до результата:** В среднем требуется **1.5-2 месяца**, чтобы найти оптимальную стратегию, которую в дальнейшем масштабируют.

**Особенности бюджета:**
- Бюджет на рекламу на старте составляет небольшие суммы
- После оптимизации кампаний вливаются необходимые суммы

---

## 📈 Анализ поисковых запросов

**Методология:**
- Краткий анализ по одному запросу на каждую услугу в городах
- Использовались данные от Яндекс
- С учетом Google, 2ГИС и других аналогичных поисковых систем, число можно умножить на **2.5**

**Примечание:** В PDF документе упоминается анализ, но конкретные данные не приведены (страницы 3-6 пустые или содержат только графики/таблицы, которые не извлеклись в текст).

## 🎯 Ключевые требования

### Функциональные требования

1. **SEO-оптимизация** - сайт должен быть оптимизирован под поисковые системы
2. **Интеграция с приложением** - форма заявки должна интегрироваться с мобильным приложением
3. **Мультигородность** - поддержка работы в разных городах
4. **Автоматизация** (для расширенной версии) - автоматическое создание страниц для новых городов

### Технические требования

1. **Админ-панель** (для расширенной версии) - возможность добавления городов через админку
2. **Единая база данных** (для расширенной версии) - синхронизация городов с приложением
3. **Аналитика** - интеграция с Яндекс.Метрикой для отслеживания метрик

### Контентные требования

1. **Семантическое ядро** - сбор и использование ключевых слов
2. **Оптимизированные тексты** - тексты, привлекающие клиентов
3. **Прайс-листы** - актуальные цены на услуги
4. **Описания услуг** - детальные описания каждой из 4 услуг
