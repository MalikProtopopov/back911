## 1. Уточняющие вопросы и допущения

### Критические вопросы с допущениями:

#### 1.1 Какой % трафика ожидаем с мобильных устройств?
**Допущение:** 70%+ (экстренные ситуации → поиск на смартфоне)  
**Последствия для дизайна:** Mobile-first подход обязателен

#### 1.2 Есть ли действующие приложения в App Store / Google Play?
**Допущение:** Приложения запущены, есть реальные метрики установок и ASO-оптимизация  
**Последствия:** Можем использовать реальные данные (рейтинги, количество установок)

#### 1.3 Какой средний чек / LTV клиента?
**Допущение:** Средний заказ 1500-3000₽, повторные заказы 30%, LTV ~5000₽  
**Последствия:** Оправдывает инвестиции в качественный дизайн и UX

#### 1.4 Есть ли бюджет на платный трафик?
**Допущение:** Да, планируется PPC → нужны лендинги под сегменты и UTM-трекинг  
**Последствия:** Создаём несколько версий Hero для A/B тестов

#### 1.5 Какой % заказов через приложение vs сайт vs звонки?
**Допущение:** Цель — 70% через приложение, 20% сайт, 10% звонки  
**Последствия:** Основной CTA — "Скачать приложение", вторичный — форма/звонок

#### 1.6 Есть ли промокоды / реферальная программа?
**Допущение:** Есть промокод "FIRST500" (500₽ на первый заказ)  
**Последствия:** Показываем в Hero и повторном CTA

#### 1.7 Какая политика privacy?
**Допущение:** Прозрачная политика, минимальные данные (имя/телефон)  
**Последствия:** Создаём страницу /privacy/ простым языком

#### 1.8 Есть ли видео-ассеты?
**Допущение:** Есть 30-сек app preview для App Store и промо-видео для Google Play  
**Последствия:** Используем в Hero (вариант 2)

#### 1.9 Планируется ли локализация?
**Допущение:** Пока только русский, но архитектура должна позволять легко добавить языки  
**Последствия:** i18n-ready структура

#### 1.10 Какие источники трафика приоритетны?
**Допущение:** SEO 40%, PPC 30%, Direct 20%, остальное 10%  
**Последствия:** Фокус на SEO-оптимизацию + быстрый путь для PPC

#### 1.11 Есть ли партнерские программы?
**Допущение:** Пока нет, но возможно в будущем  
**Последствия:** Резервируем место в навигации

#### 1.12 Какой timeline до запуска?
**Допущение:** 8-10 недель (MVP 2-4 недели дизайна + 6 недель разработки)  
**Последствия:** Фокусируемся на MVP, отсекаем nice-to-have

## 2. JTBD и сегменты аудитории

### Сегмент 1: **Экстренный водитель** (50% трафика)

#### Job to be Done:
> "Когда у меня случилась проблема с автомобилем на дороге, я хочу быстро найти надёжную помощь в моём городе, чтобы не остаться в опасности и продолжить путь"

#### Барьеры к установке приложения:
- ❌ "Нет времени разбираться, нужна помощь СЕЙЧАС"
- ❌ "Боюсь мошенников, не знаю этот сервис"
- ❌ "Не хочу устанавливать ещё одно приложение"
- ❌ "Сколько это стоит? Не обманут ли меня?"

#### Триггеры доверия:
- ✅ Мгновенная визуализация: "15 минут", "24/7", "проверенные мастера"
- ✅ Рейтинг 4.84/5 + 2728 отзывов (крупно, в первый экран)
- ✅ Прозрачные цены ("от 500₽")
- ✅ Реальные фото партнёров/автомобилей (не сток)
- ✅ "Оплата на месте или онлайн" — гибкость
- ✅ Кнопка "Позвонить" (fallback)

#### Путь на сайте:
```
Landing Hero (5 сек) → "Как работает" (10 сек) → Badge App Store/GP (клик) → Install
```

#### 3. На сайте (при повторном визите):
- Cookie-баннер: "Вернулись? Скачайте приложение со скидкой 500₽"
- Exit-intent popup: "Подождите! Установите приложение прямо сейчас"

**KPI ретаргета:**
- 20-30% CTR на ретаргетинговых баннерах
- 10-15% конверсия в install

## 4. Информационная архитектура

### 4.1 Sitemap (структура сайта)

```
/
├── / (Главная)
│
├── /cities/ (Список городов)
│   ├── /cities/{slug}/ (Страница города, например /cities/moskva/)
│   │   └── /cities/{slug}/services/{service_slug}/ (Услуга в городе)
│
├── /services/ (Список услуг)
│   └── /services/{slug}/ (Страница услуги)
│
├── /partners/ (Для партнёров)
│
├── /about/ (О компании)
│
├── /contacts/ (Контакты)
│
├── /reviews/ (Отзывы) [опционально]
│
├── /faq/ (FAQ) [опционально]
│
├── /privacy/ (Политика конфиденциальности)
│
└── /terms/ (Пользовательское соглашение)
```

**Приоритетность индексации:**
- **Tier 1** (самые важные): `/`, `/cities/{top-10}/`, `/services/shinomontazh/`
- **Tier 2**: Остальные города, остальные услуги
- **Tier 3**: Комбо-страницы город+услуга (328 страниц)

### 4.3 Sticky Install CTA (логика показа)

#### Когда показываем:
- ✅ После скролла 300px (пользователь прочитал Hero)
- ✅ На всех страницах кроме /partners/ (там другой CTA — регистрация)
- ✅ Только на мобильных устройствах (desktop — в header)

#### Когда прячем:
- ❌ Пользователь кликнул на badge (cookie "clicked_install")
- ❌ Пользователь достиг футера (не перекрываем контакты)
- ❌ Пользователь на странице /privacy/ или /terms/

#### Вид sticky CTA:
```
┌──────────────────────────────────────────────────┐
│  [Скачать приложение]  [ App Store | Google Play] │
└──────────────────────────────────────────────────┘
   ↑ Фиксируется внизу экрана, высота 56px
```

### 11.2 Метрики (KPI)

#### Конверсионные:
- **Install CTR:** 5-10% (холодный), 15-25% (горячий) — **главная метрика**
- **Lead Conversion Rate:** 2-5%
- **Bounce Rate:** < 50%
- **Time on Site:** > 2 минуты (холодный), > 45 сек (горячий)
- **Pages per Session:** > 3

#### По источникам:

| Источник     | Install CTR | Lead CR |
|-------------|-------------|---------|
| Organic     | 5-8%        | 3-5%    |
| PPC         | 10-15%      | 4-7%    |
| Direct      | 15-20%      | 2-4%    |
| Social      | 3-5%        | 1-3%    |
| Referral    | 8-12%       | 3-5%    |

#### Производительность (Core Web Vitals):
- **LCP:** < 2.5 сек
- **FID:** < 100 мс
- **CLS:** < 0.1

---

### 11.3 Гипотезы A/B тестов

#### Тест 1: Hero CTA
- **A:** Кнопка "Скачать" → модал выбора платформы
- **B:** Badges App Store + Google Play (сразу)
- **Гипотеза:** B будет выше CTR
- **Метрика:** Install CTR

#### Тест 2: Hero заголовок
- **A:** "Экстренная автопомощь за 15 минут" (срочность)
- **B:** "2,728 водителей доверяют нам" (доверие)
- **Гипотеза:** A для экстренного трафика, B для планового
- **Метрика:** Install CTR + Time on Site

#### Тест 3: Промокод
- **A:** Промокод в Hero
- **B:** Промокод в повторном CTA
- **Гипотеза:** B выше конверсия (бонус за прокрутку)
- **Метрика:** Install CTR

#### Тест 4: Отзывы
- **A:** Карусель (автопрокрутка)
- **B:** Статичный блок (3 отзыва)
- **Гипотеза:** A привлекает внимание, B удобнее читать
- **Метрика:** Scroll depth + Review interaction

#### Тест 5: Sticky CTA
- **A:** Появляется после скролла 300px
- **B:** Всегда видна
- **Гипотеза:** A менее навязчив, B выше конверсия
- **Метрика:** Install CTR (из sticky)
