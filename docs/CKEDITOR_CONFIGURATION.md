# Конфигурация CKEditor для HTML полей

## Обзор

Все HTML поля в админке Django настроены для использования CKEditor 5 с расширенной конфигурацией, которая включает поддержку стилей, цветов, шрифтов и других возможностей форматирования.

## Конфигурации CKEditor

### Конфигурация `default`

Используется для базового форматирования текста:
- Заголовки (H1-H4)
- Жирный, курсив, подчеркивание, зачеркивание
- Списки (маркированные, нумерованные)
- Ссылки
- Таблицы
- Цитаты
- Редактирование исходного кода

### Конфигурация `extends`

Расширенная конфигурация с дополнительными возможностями:
- Все возможности `default`
- **Стили текста:**
  - Размер шрифта (tiny, small, default, big, huge)
  - Семейство шрифта (Arial, Georgia, Times New Roman и др.)
  - Цвет текста
  - Цвет фона текста
- **Дополнительное форматирование:**
  - Подстрочный/надстрочный текст
  - Код
  - Выравнивание (влево, вправо, по центру, по ширине)
  - Отступы
  - Горизонтальные линии
  - Специальные символы
- **Медиа:**
  - Загрузка изображений
  - Встраивание медиа
- **Структурирование:**
  - Todo списки
  - Расширенные таблицы

## Где найти HTML поля в админке

1. **Контент города:**
   - Перейдите в: `Админка → Города → [Выберите город] → Редактировать`
   - HTML поля находятся в секции "Контент (HTML)"

2. **Контент услуги:**
   - Перейдите в: `Админка → Контент услуг → [Выберите или создайте контент]`
   - HTML поля находятся в секции "Контент (HTML)"

## Технические детали

### Файлы конфигурации

- **Настройки CKEditor:** `website_project/settings/base.py` → `CKEDITOR_5_CONFIGS`
- **Формы:** `website_api/forms.py`
- **URL маршруты:** `website_project/urls.py` → `path("ckeditor5/", include('django_ckeditor_5.urls'))`

### Использование в коде

```python
from django_ckeditor_5.widgets import CKEditor5Widget
from django import forms

class MyForm(forms.ModelForm):
    html_field = forms.CharField(
        widget=CKEditor5Widget(config_name='extends'),
        label="HTML поле",
        help_text="Описание поля"
    )
```

## Проверка работы

1. Откройте админку Django
2. Перейдите к редактированию города или контента услуги
3. В HTML полях должен появиться визуальный редактор CKEditor
4. Проверьте панель инструментов - должны быть доступны все опции форматирования

## Устранение проблем

Если редактор не появляется:

1. **Очистите кеш браузера** (Ctrl+Shift+R или Cmd+Shift+R)
2. **Проверьте консоль браузера** (F12) на наличие ошибок
3. **Убедитесь, что статические файлы собраны:**
   ```bash
   docker-compose -f docker/docker-compose.dev.yml exec web python manage.py collectstatic --no-input
   ```
4. **Проверьте, что вы залогинены в админке**
5. **Проверьте доступность статических файлов:**
   - `http://localhost:8001/static/django_ckeditor_5/dist/bundle.js`
