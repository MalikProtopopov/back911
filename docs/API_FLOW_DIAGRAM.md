# API Flow - Страница услуги в городе

```
┌─────────────────────────────────────────────────────────────────────┐
│                    СТРАНИЦА: /moskva/shinomontazh                   │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│  ВАРИАНТ 1: Простое отображение (одна цена на опцию)               │
└─────────────────────────────────────────────────────────────────────┘

    Frontend                                     Backend
       │                                            │
       │  GET /api/website/cities/moskva/          │
       │      services/shinomontazh/               │
       ├──────────────────────────────────────────>│
       │                                            │
       │                                            │ ┌──────────────┐
       │                                            │ │ City (город) │
       │                                            │ └──────────────┘
       │                                            │ ┌──────────────┐
       │                                            │ │Service (усл.)│
       │                                            │ └──────────────┘
       │                                            │ ┌──────────────┐
       │                                            │ │Options+Price │
       │                                            │ │ (опции+цены) │
       │                                            │ └──────────────┘
       │                                            │ ┌──────────────┐
       │                                            │ │Content (HTML)│
       │                                            │ └──────────────┘
       │                                            │ ┌──────────────┐
       │                                            │ │SEO (мета)    │
       │                                            │ └──────────────┘
       │                                            │
       │  {                                         │
       │    city: {...},                           │
       │    service: {...},                        │
       │    options: [{price: {...}}],             │
       │    content: {...},                        │
       │    seo: {...}                             │
       │  }                                         │
       │<──────────────────────────────────────────│
       │                                            │
   ┌───┴────┐
   │Рендерим│
   │страницу│
   └────────┘


⚠️  ПРОБЛЕМА: Каждая опция имеет только ОДНУ цену
    
    options: [
      {
        title: "Балансировка колеса",
        price: {
          amount: "500.00",
          technic_category: "Грузовой"  // ← Только одна категория!
        }
      }
    ]
    
    Если в БД есть:
    - Грузовой: 500 руб.
    - Легковой: 300 руб.
    - Кроссовер: 350 руб.
    
    → Вернётся только "Грузовой: 500 руб."


┌─────────────────────────────────────────────────────────────────────┐
│  ВАРИАНТ 2: Lazy Loading (загрузка деталей по требованию)          │
└─────────────────────────────────────────────────────────────────────┘

    Frontend                                     Backend
       │                                            │
       │  GET /api/website/cities/moskva/          │
       │      services/shinomontazh/               │
       ├──────────────────────────────────────────>│
       │                                            │
       │  { city, service, options, ... }          │
       │<──────────────────────────────────────────│
       │                                            │
   ┌───┴────┐
   │Рендерим│
   │страницу│
   └───┬────┘
       │
   ┌───┴────────┐
   │Пользователь│
   │кликает на  │
   │опцию №1    │
   └───┬────────┘
       │
       │  GET /api/website/options/1/              │
       ├──────────────────────────────────────────>│
       │                                            │
       │                                            │ ┌──────────────┐
       │                                            │ │OptionPrice[] │
       │                                            │ │ВСЕ цены по   │
       │                                            │ │всем городам  │
       │                                            │ │и категориям  │
       │                                            │ └──────────────┘
       │                                            │
       │  {                                         │
       │    id: 1,                                  │
       │    title: "Балансировка",                 │
       │    prices: [                               │
       │      {city: "moskva", tech: "Грузовой", amount: "500"},│
       │      {city: "moskva", tech: "Легковой", amount: "300"},│
       │      {city: "moskva", tech: "Кроссовер", amount: "350"},│
       │      {city: "spb", tech: "Грузовой", amount: "450"},   │
       │      ...                                   │
       │    ]                                       │
       │  }                                         │
       │<──────────────────────────────────────────│
       │                                            │
   ┌───┴─────────┐
   │Фильтруем по │
   │city="moskva"│
   └───┬─────────┘
       │
   ┌───┴─────────┐
   │Показываем   │
   │модальное окно│
   │с ценами по  │
   │категориям   │
   └─────────────┘


✅  ПЛЮСЫ:
    - Быстрая загрузка страницы (1 запрос)
    - Детали загружаются только при необходимости
    - Не перегружаем сеть лишними данными

❌  МИНУСЫ:
    - Задержка при клике на опцию
    - Дополнительные запросы


┌─────────────────────────────────────────────────────────────────────┐
│  ВАРИАНТ 3: Предзагрузка всех цен (не рекомендуется)               │
└─────────────────────────────────────────────────────────────────────┘

    Frontend                                     Backend
       │                                            │
       │  GET /api/website/cities/moskva/          │
       │      services/shinomontazh/               │
       ├──────────────────────────────────────────>│
       │                                            │
       │  { options: [45 опций] }                  │
       │<──────────────────────────────────────────│
       │                                            │
   ┌───┴────┐
   │ Для    │
   │ каждой │  GET /api/website/options/1/
   │ опции  ├──────────────────────────────────────>
   │ делаем │  GET /api/website/options/2/
   │ запрос ├──────────────────────────────────────>
   │        │  GET /api/website/options/3/
   │ (45    ├──────────────────────────────────────>
   │ запро- │  ...
   │ сов!)  ├──────────────────────────────────────>
   └───┬────┘  GET /api/website/options/45/
       │      ────────────────────────────────────>
       │                                            │
       │  45 ответов с ценами                      │
       │<══════════════════════════════════════════│
       │                                            │
   ┌───┴─────────┐
   │Фильтруем все│
   │цены по      │
   │city="moskva"│
   └───┬─────────┘
       │
   ┌───┴─────────┐
   │Рендерим     │
   │страницу с   │
   │полными      │
   │данными      │
   └─────────────┘


❌  ПРОБЛЕМА N+1:
    1 запрос для страницы + 45 запросов для опций = 46 запросов!

✅  ПЛЮСЫ:
    - Все данные доступны сразу
    - Нет задержек при взаимодействии

❌  МИНУСЫ:
    - Очень медленная загрузка страницы
    - Много запросов к API
    - Избыточные данные (цены по другим городам)


┌─────────────────────────────────────────────────────────────────────┐
│  ВАРИАНТ 4: Изменение API (ОПТИМАЛЬНО, требует доработки)          │
└─────────────────────────────────────────────────────────────────────┘

    Frontend                                     Backend
       │                                            │
       │  GET /api/website/cities/moskva/          │
       │      services/shinomontazh/               │
       ├──────────────────────────────────────────>│
       │                                            │
       │                                            │ ┌──────────────┐
       │                                            │ │ Изменённый   │
       │                                            │ │ сериализатор:│
       │                                            │ │              │
       │                                            │ │ price → prices│
       │                                            │ │ (массив!)    │
       │                                            │ └──────────────┘
       │                                            │
       │  {                                         │
       │    city: {...},                           │
       │    service: {...},                        │
       │    options: [                             │
       │      {                                     │
       │        title: "Балансировка",             │
       │        prices: [  ← МАССИВ!               │
       │          {amount: "500", tech: "Грузовой"},│
       │          {amount: "300", tech: "Легковой"},│
       │          {amount: "350", tech: "Кроссовер"}│
       │        ]                                   │
       │      }                                     │
       │    ]                                       │
       │  }                                         │
       │<──────────────────────────────────────────│
       │                                            │
   ┌───┴────┐
   │Рендерим│
   │страницу│
   │с выбором│
   │категории│
   └────────┘


✅  ПЛЮСЫ:
    - Один запрос для всех данных
    - Нет проблемы N+1
    - Оптимальное количество данных
    - Фронтенд может сам выбирать категорию

⚠️  МИНУСЫ:
    - Требует изменения бекенда
    - Breaking change для фронтенда (price → prices)


┌─────────────────────────────────────────────────────────────────────┐
│  ДОПОЛНИТЕЛЬНЫЙ ЭНДПОИНТ: Категории техники                         │
└─────────────────────────────────────────────────────────────────────┘

    Frontend                                     Backend
       │                                            │
       │  GET /api/website/technic-categories/     │
       │      ?service__slug=shinomontazh          │
       ├──────────────────────────────────────────>│
       │                                            │
       │  {                                         │
       │    count: 2,                               │
       │    results: [                              │
       │      {id: 1, title: "Грузовой"},          │
       │      {id: 3, title: "Легковой"}           │
       │    ]                                       │
       │  }                                         │
       │<──────────────────────────────────────────│
       │                                            │
   ┌───┴────┐
   │Рендерим│
   │фильтр  │
   │категорий│
   └────────┘


📊  ИСПОЛЬЗОВАНИЕ:
    - Для отображения выпадающего списка категорий
    - Для фильтрации цен на фронтенде
    - Для валидации выбора пользователя


┌─────────────────────────────────────────────────────────────────────┐
│  ИТОГОВЫЕ РЕКОМЕНДАЦИИ                                              │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────┬─────────────────────┬─────────────────────┐
│   Простое решение   │  Текущее решение    │  Оптимальное решение│
│   (сейчас)          │  (lazy loading)     │  (требует доработки)│
├─────────────────────┼─────────────────────┼─────────────────────┤
│ 1 запрос            │ 1 + N запросов      │ 1 запрос            │
│ Быстро              │ Средняя скорость    │ Быстро              │
│ Одна цена на опцию  │ Все цены            │ Все цены            │
│ ⭐⭐⭐               │ ⭐⭐                 │ ⭐⭐⭐⭐⭐           │
└─────────────────────┴─────────────────────┴─────────────────────┘


📝  ВЫБОР СТРАТЕГИИ:

1. Если на странице НЕ нужны цены по категориям:
   → Используй Вариант 1 (простое решение)

2. Если нужны цены по категориям, но не критична задержка при клике:
   → Используй Вариант 2 (lazy loading)

3. Если нужны цены по категориям И важна скорость:
   → Измени API (Вариант 4)

4. НИКОГДА не используй Вариант 3 (предзагрузка всех цен)
```
